# FF7 for St. Jude

This is an app to display content for the ["FF7 for St. Jude" campaign](https://ff7forstjude.org). It pulls supporting campaigns and for each of those campaigns, it makes a request to the [Tiltify API](https://developers.tiltify.com/docs/intro) to get donations, rewards, and targets.
